# Level 1 — 我会和 AI 对话

## 目标

- 把「模糊的想法」变成「清晰的指令」
- 知道一个好 Prompt 长什么样
- 能引导 AI 不跑偏

## 需要知道什么

- Prompt 是什么（[入门第 4 章](../getting-started/04-your-first-prompt.md)）
- 好 Prompt 的公式：角色 + 目标 + 背景 + 约束 + 第一步
- 常见坑：一次要求太多、只描述感觉、不看结果

## 练习项目

连续 3 天，每天用 [start-project](../../prompts/start/start-project.md) 描述一个新想法：

- 第 1 天：个人网站
- 第 2 天：记录每天喝水的工具
- 第 3 天：你自己的真实想法

每次都记录：AI 问了什么问题？你是如何回答的？

## 毕业标准

- [ ] 我能写出包含「目标 + 背景 + 约束」的 Prompt
- [ ] AI 跑偏时，我知道怎么把它拉回来（例如说「先不要写代码」）
- [ ] 我积累了至少 3 次对话记录
