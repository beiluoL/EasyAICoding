# Level 0 — 我完全不会编程

## 目标

- 不再害怕「编程」这个词
- 明白 AI Coding 的基本工作方式
- 建立第一个真实想法

## 需要知道什么

- 什么是 AI Coding（[概念](../getting-started/01-what-is-ai-coding.md)）
- 什么是 Vibe Coding（[概念](../getting-started/02-what-is-vibe-coding.md)）
- 你的工具能做什么（[选择工具](../getting-started/03-choose-your-ai-tool.md)）

关键心态：**你不需要先学会编程，才能开始。先开始，再学会。**

- [start-project](../../prompts/start/start-project.md)：把想法变成项目的第一步
- [ask-ai-correctly](../../prompts/start/ask-ai-correctly.md)：学会正确提问

## 推荐 Tutorial

- [Getting Started 入门](../getting-started/README.md)（读完前 3 章即可）

## 练习项目

不用做软件。只做：

1. 在备忘录里写下一个想法：我想做一个 ____
2. 给它写一句话说明：它帮谁解决什么问题
3. 打开你的 AI 工具，向它介绍你自己和这个想法

## 毕业标准

- [ ] 我能用自己的话解释「AI Coding 是什么」
- [ ] 我选好了一个 AI 工具并打开过它
- [ ] 我写下了一个真实想法
- [ ] 我给 AI 发过至少一条消息
