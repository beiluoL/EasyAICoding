# 📚 Learning Roadmap（学习路线）

不知道从哪开始？先找到你现在的 Level。

## Level 概览

| Level | 名字 | 一句话 |
| --- | --- | --- |
| [Level 0](level-0.md) | 我完全不会编程 | 从零开始，先建立信心 |
| [Level 1](level-1.md) | 我会和 AI 对话 | 学会把想法说清楚 |
| [Level 2](level-2.md) | 我可以让 AI 帮我写代码 | 完成第一个真实文件 |
| [Level 3](level-3.md) | 我可以完成一个小项目 | 完整做出一个能用的应用 |
| [Level 4](level-4.md) | 我可以 Debug / Test / Deploy | 解决错误、验证功能、部署上线 |
| [Level 5](level-5.md) | 我可以独立使用 AI 构建软件 | 从想法到上线全程自己走 |

## 怎么判断自己在哪一级

诚实回答：

- 我写过任何代码吗？→ 没有，从 [Level 0](level-0.md) 开始
- 我知道怎么给 AI 发消息吗？→ 不确定，先看 [Level 1](level-1.md)
- 我让 AI 写出过一个能运行的文件吗？→ 没有，先做 [Level 2](level-2.md)
- 我独立完成过一个小项目吗？→ 没有，先做 [Level 3](level-3.md)
- 我能自己 Debug 吗？→ 不能，从 [Level 4](level-4.md) 开始

## 使用建议

1. **不要跳级**：每一级都建立在前一级之上
2. **完成毕业标准再升级**：每级末尾有「毕业标准」
3. **不用一次学完**：每天 30 分钟，按自己的节奏
4. **遇到困难回头看**：Debug 库和 FAQ 永远可以回来查

## 路线与内容的关系

```text
Level 0 → Getting Started 入门
Level 1 → Prompts 提示词库
Level 2 → Tutorials 教程
Level 3 → Cases 案例
Level 4 → Debugging 调试库 + Testing
Level 5 → 组合使用所有内容
```
