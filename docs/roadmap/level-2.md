# Level 2 — 我可以让 AI 帮我写代码

## 目标

- 让 AI 生成代码，并把它变成能运行的文件
- 理解「运行」和「报错」是正常过程
- 会使用最基本的 Debug 方法

## 需要知道什么

- 文件是什么、文件夹是什么
- 如何新建文件、保存文件、重命名文件
- 如何用浏览器或终端运行一个文件
- 遇到错误时，把「现象 + 错误信息」完整发给 AI

## 练习项目

让 AI 帮你做：

1. 一个 `index.html` 个人主页
2. 一个 `todo.html` 待办清单（只用 HTML + CSS + JavaScript）
3. 一个 `counter.html` 计数器（按钮 +1/-1）

每个都要求：只创建需要的文件，先运行再继续。

## 毕业标准

- [ ] 我独立让 AI 创建了 3 个能运行的文件
- [ ] 我遇到至少 1 次报错，并成功让 AI 修复
- [ ] 我能说出「运行」是什么意思
