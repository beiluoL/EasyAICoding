# Level 3 — 我可以完成一个小项目

## 目标

- 完成一个「有多个功能」的小项目
- 学会拆任务：大目标 → 小任务
- 学会管理项目状态：这一步做完了吗？

## 需要知道什么

- 什么是 MVP（Minimum Viable Product，最小可用版本）
- 如何把项目拆成 Step 1 / Step 2 / Step 3
- 项目文件的基本结构（HTML / CSS / JavaScript / README）
