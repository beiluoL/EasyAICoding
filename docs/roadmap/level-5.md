# Level 5 — 我可以独立使用 AI 构建软件

## 目标

- 从想法到上线，全程独立完成
- 能自己规划项目、控制节奏、验证结果
- 建立自己的作品集

## 需要知道什么

- 完整流程：Idea → Requirement → Design → Build → Debug → Test → Deploy
- 如何选择技术栈（[概念：前端 / 后端 / 数据库](../concepts/README.md)）
- 如何记录和复盘自己的项目

## 练习项目

做一个你自己的真实想法项目，完整走完流程：

1. 用 [project-idea 模板](../../templates/project-idea.md) 写下想法
2. 用 [requirement 模板](../../templates/requirement.md) 写需求
3. 用 [development-plan 模板](../../templates/development-plan.md) 拆步骤
4. 用 [Case 结构](../../cases/README.md) 记录过程
5. 部署上线，把链接放进作品集

## 毕业标准

- [ ] 我独立完成了一个「从想法到上线」的项目
- [ ] 我记录了完整的案例（requirements / steps / verification / lessons）
- [ ] 我能教另一个小白开始（尝试为 EasyAICoding 贡献一个 [Case](../../CONTRIBUTING.md)）

## 恭喜 🎉

你完成了整个学习路线。现在你可以：

- 继续做新项目
- 为 EasyAICoding 贡献内容（[贡献指南](../../CONTRIBUTING.md)）
- 帮助其他新手（这是让知识最牢固的方法）
