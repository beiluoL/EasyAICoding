# 其他 AI Coding 工具

AI Coding 工具不止三个。这里简单列出其他常见选项，具体操作请以各自官方文档为准。

## 常见选项

### VS Code + AI 插件（例如 GitHub Copilot）

- 它是什么：在流行的免费编辑器 VS Code 里安装 AI 插件
- 适合谁：已经用 VS Code 或想用免费编辑器的人
- 怎么开始：安装 VS Code → 安装插件 → 登录

### Windsurf

- 它是什么：带 AI 的代码编辑器，和 Cursor 类似
- 适合谁：想尝试不同编辑器体验的人

### Trae

- 它是什么：字节跳动推出的 AI IDE
- 适合谁：中文界面、国内网络环境下想尝试的人

### 在线编程环境（如 Replit）

- 它是什么：浏览器里就能写代码和运行的环境
- 适合谁：不想在本地安装任何软件的人

## 怎么选

判断标准不是「哪个最强」，而是：

1. 能不能顺利安装
2. 界面顺不顺手
3. 能不能在项目文件夹里工作

都可以用 [start-project Prompt](../../prompts/start/start-project.md) 开始第一个项目。
