# Frontend（前端）

## 定义

**Frontend（前端）**：用户直接看到、点击、交互的部分。

大白话：**前端是软件的「脸」和「皮肤」。** 你打开网页看到的按钮、图片、文字，都属于前端。

## 例子

一个 Todo 应用里：

- 输入框（「今天要做什么？」）
- 添加按钮
- 待办列表
- 删除按钮

这些都是前端。

## 前端常用的三种语言

| 语言 | 大白话 | 作用 |
| --- | --- | --- |
| HTML | 骨架 | 决定页面上有什么内容 |
| CSS | 衣服 | 决定颜色、大小、布局好不好看 |
| JavaScript | 肌肉 | 决定页面能不能动、能不能响应点击 |

## 新手最常接触的场景

- 网页长得不好看 → 改 CSS
- 页面没有内容 → 改 HTML
- 按钮点了没反应 → 改 JavaScript

## 什么时候只需要前端

如果软件**不需要保存数据**、**不需要登录**、**不需要从服务器获取内容**，纯前端就够了。

例如：个人网站、计算器、随机抽签工具。

## 什么时候需要后端

需要保存数据、登录、处理复杂逻辑时，前端就不够了。见 [Backend（后端）](backend.md)。
