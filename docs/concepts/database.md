# Database（数据库）

## 定义

**Database（数据库）**：按照一定结构长期保存数据的软件。

大白话：**数据库是软件的「仓库」。** 你把数据放进去，下次还能取出来。

## 例子

Todo 应用：

```text
用户添加「买牛奶」
↓
后端把这条记录写进数据库
↓
用户明天打开应用
↓
后端从数据库读出来，显示在页面上
```

如果不用数据库，关掉浏览器，「买牛奶」就消失了。

## 常见的数据库概念（大白话版）

| 术语 | 大白话 |
| --- | --- |
| Table（表） | 一个「表格」，例如 todos 表 |
| Record / Row（记录） | 表格里的一行，例如一条任务 |
| Field / Column（字段） | 表格里的一列，例如「任务内容」「完成状态」 |
| Query（查询） | 从数据库里取数据的操作 |

## 新手常见问题

### 1. 数据库装不上 / 启动失败

→ 看 [Debug 案例：数据库连接失败](../../debugging/common-errors/database-connection-failed.md)

### 2. 需要很复杂的数据库吗？

不需要。V0.1 阶段：

- 数据量小、单用户 → 可以用 SQLite（一个文件就是数据库，最简单）
- 数据要放公网、多人用 → 再用托管数据库（PostgreSQL 等）

### 3. 不懂 SQL 能行吗？

能。让 AI 帮你写数据库操作代码，你只需要理解「存数据」和「取数据」这两个概念。

## 什么时候引入数据库

- 数据要长期保存（重启后还在）→ 需要
- 数据刷新页面就丢也没关系 → 暂不需要
