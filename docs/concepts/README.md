# 📖 Concepts（概念解释）

这里用「专业术语 + 大白话」的方式解释 AI Coding 路上的核心概念。

第一次看到不懂的词，先来这里查。

## 概念列表

| 概念 | 大白话 | 什么时候需要它 |
| --- | --- | --- |
| [Prompt（提示词）](prompt.md) | 你发给 AI 的话 | 每次和 AI 对话 |
| [Context（上下文）](context.md) | AI 能看到的背景信息 | AI「忘记」你的项目时 |
| [Project（项目）](project.md) | 一个软件的全部文件 | 从第一个项目开始 |
| [Frontend（前端）](frontend.md) | 用户看到的界面 | 做网页、App 界面 |
| [Backend（后端）](backend.md) | 用户看不到的逻辑 | 数据要保存、要登录时 |
| [Database（数据库）](database.md) | 长期保存数据的地方 | 数据要重启后还在时 |
| [Deployment（部署）](deployment.md) | 让软件上线可访问 | 分享给别人用时 |

## 进阶概念（V0.1 不展开）

以下概念属于进阶内容，V0.1 暂不深入讲解，只列出名字，避免新手一开始就被吓到：

- Agentic Workflow（智能体工作流）
- Context Engineering（上下文工程）
- State Machine（状态机）
- Reflection（反思机制）
- Multi-Agent（多智能体）

不用按顺序读。用到哪个查哪个，查完继续做项目。
