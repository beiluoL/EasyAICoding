# FAQ（常见问题）

## 1. 我完全不会编程，真的能行吗？

能。这个项目就是为「完全不会编程的人」设计的。你不需要先学编程，只要从 [Start Here](../getting-started/README.md) 开始，一步步来。

## 2. AI 写出来的代码安全吗？

AI 只是工具，最终检查和运行的是你。遵守：

- 不把 API Key、密码放进代码
- 下载 AI 建议的软件包时，先问 AI 它是干什么的
- 涉及账号、支付的功能，先了解风险或请教懂行的人

## 3. AI 写的代码跑不起来怎么办？

正常！连专业程序员也经常遇到。按 [Debug 流程](../../debugging/README.md)：

1. 复制完整错误信息
2. 告诉 AI 你做了什么
3. 让 AI 修复

## 4. 我应该学 Python 还是 JavaScript？

先不纠结语言。V0.1 建议：

- 想做网页 → JavaScript（前端三大件之一）
- 想做 AI 工具、数据处理 → Python

具体由你的项目和 AI 决定，见 [选择工具](../getting-started/03-choose-your-ai-tool.md)。

## 5. 需要学英语吗？

不需要流利英语。中文直接说就行，错误信息看不懂就复制给 AI 让它解释。

## 6. 工具要花钱吗？

不同工具有免费额度和付费计划，以官方文档为准。很多工具都有免费档，足够完成 V0.1 的项目。

## 7. 项目做好了怎么让别人用？

部署上线。见 [Deployment（部署）](../concepts/deployment.md) 和 [deploy-project Prompt](../../prompts/deployment/deploy-project.md)。

## 8. 这个仓库里的教程都验证过了吗？

没有。遵循「Evidence over Claims（证据优先）」原则，每个文件都标注了 `Verification` 状态。没有写验证结果的就是 `Not Yet Verified`。

## 9. 我做完一个项目了，下一步做什么？

按 [Learning Roadmap](../roadmap/README.md) 升到下一级，或者把你的项目记录成 [Case](../../cases/README.md) 分享给大家。
