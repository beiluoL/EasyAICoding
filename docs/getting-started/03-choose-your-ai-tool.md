# 03 · 选择你的 AI 工具

## 问题

> Codex、Claude Code、Cursor……工具太多了，我该用哪个？

## 重要原则

本项目**不声称**某个工具一定「最好」。工具在快速更新，请以官方文档为准。

选择工具看三件事：

1. 你用什么系统（Windows / macOS / Linux）
2. 你想做网页、App 还是 AI 工具
3. 你愿意花多少时间配置环境

## 工具一览

| 工具 | 一句话是什么 | 适合谁 | 怎么开始 |
| --- | --- | --- | --- |
| [Codex](codex.md) | OpenAI 的 AI Coding 工具，可以在终端或桌面 App 里和 AI 协作 | 想要「对话式」构建项目的人 | 官方下载安装，登录后即可 |
| [Claude Code](claude-code.md) | Anthropic 的终端 AI 编程工具 | 习惯命令行、愿意看文字输出的人 | 官方文档安装，首次运行登录 |
| [Cursor](cursor.md) | 带 AI 的代码编辑器，看起来像 VS Code | 想在可视化编辑器里工作的人 | 官方下载，打开文件夹即可开始 |
| [其他工具](other-tools.md) | 包括 VS Code + Copilot、Windsurf、Trae 等 | 因人而异 | 以各自官方文档为准 |

## 三个常见选择路径

### 路径 A：完全不想碰命令行

→ 优先试 **Cursor** 或桌面版 AI 工具。它像普通软件一样安装，界面是可视化的。

### 路径 B：能接受打开终端（Terminal）

→ 可以试 **Codex** 或 **Claude Code**。它们更「对话式」，适合一步步构建。

### 路径 C：已经在用 VS Code

→ 在 VS Code 里装 AI 插件是最平滑的开始，不用换编辑器。

## 怎么才算「选好了」

你不需要研究完所有工具。标准很简单：

> 装好一个工具 → 能打开它 → 能向它发出第一条消息。

做到这三步，就选好了。

## 实践

1. 选定一个工具
2. 按对应 [Tool Guide](../tools/README.md) 安装
3. 发一条消息：「你好，我想做一个网站，但我不会编程，请用最简单的语言帮我。」

## 安装命令说明

工具的安装命令变化很快。本仓库的 [Tool Guides](../tools/README.md) 只提供方向性说明，具体命令**请以官方文档为准**。
