# 05 · 你的第一个项目

## 问题

> 我会发 Prompt 了，现在真的做一个项目出来看看？

## 我们做什么

做一个**个人介绍网页**，只需要一个文件，任何电脑都能打开。

最终效果：浏览器里显示一个页面，上面有你的名字、一句话介绍、一个按钮。

这是难度最低、成功率最高的第一个项目。

## 准备工作

- 一个 AI Coding 工具（[不会选？](03-choose-your-ai-tool.md)）
- 一个文件夹，用来放你的项目（例如桌面新建文件夹 `my-website`）
- 约 30 分钟

## Step 1 · 让 AI 创建项目

把这条 Prompt 发给 AI：

```text
帮我创建一个个人介绍网页项目：

- 只有一个 index.html 文件
- 浅色背景，简洁风格
- 显示我的名字：{{你的名字}}
- 一句话介绍：{{你的介绍}}
- 一个按钮，点击后显示「你好，我是 {{你的名字}}」

先不要创建多余文件，只创建 index.html。
```

## Step 2 · 把代码保存成文件

AI 会给你一段代码。在项目文件夹里新建一个文件，命名为 `index.html`，把代码完整粘贴进去并保存。

> 小提示：如果 AI 给了多个文件，先只取 `index.html`。其他文件可以先不要。

## Step 3 · 运行

双击 `index.html`，或用浏览器打开它。

**预期看到**：一个显示你名字的网页，按钮点击后有反应。

## Step 4 · 遇到问题就 Debug

如果页面是空白、报错或和预期不一样，复制这条 Prompt 发给 AI：

```text
我按照你的指示创建了 index.html，但出现了以下问题：

现象：{{描述你看到什么}}
错误信息：{{如果有，粘贴完整错误信息}}

请帮我找出原因，并用最少的修改修复它。
```

更多方法见 [Debugging（调试库）](../../debugging/README.md)。

## Step 5 · 修改并继续

试试让 AI 修改：

- 换一个颜色主题
- 加一张图片
- 加第二个页面

每次都遵循：**改一步 → 运行 → 验证 → 再继续**。

## 完成标准

- [ ] 我创建了 `index.html`
- [ ] 我用浏览器打开了它
- [ ] 我看到了自己的名字和按钮
- [ ] 我成功修改过一次

## 常见错误

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 双击没反应 / 打不开 | 文件不是 `.html` 结尾 | 检查文件名和扩展名 |
| 页面是空白 | 代码没保存，或复制不完整 | 重新复制完整代码再保存 |
| 按钮没反应 | JavaScript 有错 | 把现象发给 AI 修复 |
