# 02 · 什么是 Vibe Coding？

## 问题

> 我听说「Vibe Coding」这个词，它和 AI Coding 有什么区别？

## 定义

**Vibe Coding = 使用自然语言与 AI 协作完成软件开发。**

大白话：你不再一句一句写代码，而是用聊天的方式「带着感觉」和 AI 一起把软件做出来。

名字里的 Vibe 来自「跟着感觉走」：你描述感觉、描述想法、描述效果，AI 负责把这些变成代码。

## 一个例子

你不需要写出：

```html
<div class="card" style="background: #ffe4ec; border-radius: 16px;">
  <h1>生日快乐</h1>
</div>
```

你只需要说：

> 「做一个生日卡片，粉色的、圆角的、看起来温暖一点。」

AI 会帮你处理「粉色」、「圆角」、「温暖」对应的代码。

## Vibe Coding 的正确用法

好的 Vibe Coding 不是「随便说说，AI 全包」，而是：

1. **说清楚目标**：我要做什么、给谁用
2. **一次只做一小步**：先做首页，再做按钮
3. **运行并验证**：每一步都运行看看
4. **把错误交给 AI**：报错就把错误信息发给 AI
5. **自己也要理解基础**：不一定能写，但要能看懂大概

## 常见的坑

| 坑 | 表现 | 建议 |
| --- | --- | --- |
| 一次要求太多 | AI 写出一大堆代码，跑不起来 | 拆成小任务，一个一个来 |
| 只描述感觉 | 「做一个高端大气的网站」 | 加上具体内容：什么页面、什么功能 |
| 不看结果 | 代码是生成了，但没运行 | 先学会「运行」再继续 |
| 报错就慌 | 看到英文错误就放弃 | 复制错误信息，交给 AI 和 [Debug 流程](../../debugging/README.md) |

## 实践

用一个 Prompt 练习「说清楚目标」。填空：

> 我想做一个 `_____`，给 `_____` 用。它最重要的功能是 `_____`。请先不要写代码，先问我几个问题，把需求弄清楚。
