# 🚀 Start Here（从这里开始）

欢迎来到 EasyAICoding！

如果你完全不会编程，这里是你的第一站。不需要任何准备，只要你会打字、会打开网页，就可以开始。

## 你需要知道的第一件事

**AI Coding（AI 编程）= 用自然语言告诉 AI 你想做什么，让 AI 帮你写代码。**

你不用一开始就懂代码。你要做的是：

1. 说出你的想法
2. 让 AI 帮你拆成小步骤
3. 一步一验证
4. 遇到错误就把错误信息交给 AI

## 阅读顺序

建议按顺序读，每一章只要 5-10 分钟：

1. [01 · 什么是 AI Coding？](01-what-is-ai-coding.md)
2. [02 · 什么是 Vibe Coding？](02-what-is-vibe-coding.md)
3. [03 · 选择你的 AI 工具](03-choose-your-ai-tool.md)
4. [04 · 你的第一条 Prompt](04-your-first-prompt.md)

## 5 分钟快速开始

不想读长篇？先做这三步：

1. 打开一个 AI Coding 工具（[不知道怎么选？看这里](03-choose-your-ai-tool.md)）
2. 复制 [start-project Prompt](../../prompts/start/start-project.md)，把 `{{IDEA}}` 换成你的想法
3. 把 AI 的回答发给它之前，先告诉它：「先不要写代码，先帮我拆步骤」

## 遇到问题怎么办

- 先查 [FAQ（常见问题）](../faq/README.md)
- 再查 [Debug Library（调试库）](../../debugging/README.md)
- 都不行，就带着错误信息去问 AI，或者提交 [Issue](../../CONTRIBUTING.md)
