# 01 · 什么是 AI Coding？

## 问题

> 我一直以为编程是程序员才能做的事。AI Coding 是什么？我能用吗？

## 一个例子

想象你要做一张生日贺卡网页。以前的做法是：

1. 学 HTML（网页标记语言）
2. 学 CSS（网页样式语言）
3. 学 JavaScript（让网页动起来的语言）
4. 学几个月，终于能写出贺卡

用 AI Coding 的做法是：

> 告诉 AI：「帮我做一个生日贺卡网页，粉色背景，有气球动画，上面写『生日快乐，小明』。」

AI 会直接给你一个可以运行的网页文件。你复制、保存、打开浏览器，就能看到效果。

## 解释

**AI Coding（AI 编程）**：用自然语言（也就是我们平时说话的方式）和 AI 协作，让 AI 帮你编写、修改、修复代码。

大白话：**你当「产品经理」，告诉 AI 你要什么；AI 当「程序员」，帮你把代码写出来。**

几个常用术语：

| 术语 | 大白话 |
| --- | --- |
| Prompt（提示词） | 你发给 AI 的话 |
| Code（代码） | 让电脑做事的文字指令 |
| Run（运行） | 让代码真正执行起来 |
| Debug（调试） | 找出并修复代码里的错误 |

## 但 AI 不是魔法

AI Coding 不是「说一句话，软件自动完成」。它更像请了一个非常聪明、但偶尔会犯错的实习生：

- 它能写出大部分代码
- 但它需要你说清楚需求
- 它写的代码可能需要运行才知道对不对
- 出错了，你需要把错误信息反馈给它

这就是为什么本项目的路线是：**Idea → Requirement → Design → Build → Debug → Test → Deploy**。

## 实践

现在不用做任何事，只做一个小练习：

用你自己的话，回答三个问题：

1. 我想做一个什么软件？
2. 它解决谁的什么问题？
3. 它最核心的一个功能是什么？

写在纸上、备忘录里都可以。这是你的 **Idea（想法）**，后面所有步骤都从它开始。
