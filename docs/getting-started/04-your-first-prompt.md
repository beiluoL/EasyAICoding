# 04 · 你的第一条 Prompt

## 问题

> 工具装好了，现在我要对 AI 说什么？

## Prompt 是什么

**Prompt（提示词）**：你发给 AI 的指令，可以是问题、任务或对话开头。

大白话：**Prompt 就是你「怎么开口跟 AI 说」。**

## 新手最常见的错误 Prompt

❌ 「帮我写个网站。」

问题：AI 不知道你要什么网站、给谁用、做成什么样，只能猜。猜出来的通常不是你要的。

## 一个好 Prompt 的公式

```text
角色 + 目标 + 背景 + 约束 + 第一步
```

| 部分 | 意思 | 例子 |
| --- | --- | --- |
| 角色 | 让 AI 以什么身份回答 | 「你是耐心的编程老师」 |
| 目标 | 你要什么 | 「帮我做一个记录每日喝水的小网页」 |
| 背景 | 你的情况 | 「我完全不会编程，用的是 Codex」 |
| 约束 | 不能做什么 | 「先不要写代码」 |
| 第一步 | 先做什么 | 「先问我 5 个问题把需求弄清楚」 |

## 你的第一条 Prompt（直接复制）

```text
你是耐心的编程老师，面对完全不会编程的新手。

我想做一个：{{在这里写下你的想法}}

我完全不会编程，用的是 {{你的工具名}}。

请你：
1. 先不要写代码
2. 问我几个问题，把需求弄清楚
3. 然后告诉我这个项目最简单的实现方式
4. 设计一个最小可用版本（MVP，Minimum Viable Product）
5. 把它拆成 5 个以内的小步骤
6. 每完成一步，再让我继续下一步
```

## 动手做

1. 打开你的 AI 工具
2. 把上面这段复制进去
3. 把 `{{在这里写下你的想法}}` 换成你的真实想法
4. 把 `{{你的工具名}}` 换成工具名
5. 发送，然后看 AI 问你什么问题

## 预期结果

- AI 没有直接甩给你一大段代码
- AI 在问问题、澄清需求
- 你感觉「这事好像可以做」

如果 AI 直接开始写代码，就回复：

> 请先不要写代码，先帮我拆步骤。
