# 内容质量标准

EasyAICoding 的所有内容都应尽可能满足以下标准：

## 1. Clear（清晰）

- 一句话能说清「这篇内容帮读者解决什么问题」
- 步骤编号清晰：Step 1 → Step 2 → Step 3
- 不使用模糊表述：「可能」「大概」「应该可以」

## 2. Beginner Friendly（新手友好）

- 默认读者完全不会编程
- 第一次出现的专业术语必须给大白话解释
- 例子优先于抽象概念
- 不要一次引入多个新概念

## 3. Actionable（可执行）

- 读者看完知道「下一步做什么」
- 提供可直接复制的内容（Prompt、代码、命令）
- 每个步骤都有明确的完成标志

## 4. Reproducible（可复现）

- 步骤可以被另一个人按顺序重复
- 提供 Expected Result（预期结果）
- 环境差异（操作系统、工具版本）要说明
- 无法复现的内容标记 `Not Yet Verified`

## 5. Current（不过时）

- 不写具体版本号过死的安装命令
- 涉及工具操作时注明「请以官方文档为准」
- 尽量写「概念和方法」，少写「某个按钮的确切位置」

## 6. Honest（诚实）

- 没有验证就不写「亲测有效」「已经完成」
- 明确标注验证状态：

```text
Verification: Not Yet Verified
```

- 失败案例同样有价值：写清楚症状、原因、解决

## 禁止使用的表述

以下表述没有证据支撑，一律避免：

- 「这是最好的……」
- 「100% 成功」
- 「绝对不会出错」
- 「每个人都应该……」
- 「AI 已经完成了」（除非附验证过程）

## 检查清单

提交内容前，自查：

- [ ] 读者知道「这篇解决什么问题」
- [ ] 术语都有解释
- [ ] 步骤可以照着做
- [ ] 有 Expected Result 或 Verification
- [ ] 没有「最好 / 100% / 绝对」类表述
- [ ] 没有 API Key、密码
- [ ] 链接没有写死到不存在的路径
