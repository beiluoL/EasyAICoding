## 重要原则

这个仓库坚持：

1. **Beginner First（小白优先）** —— 所有内容默认你不会编程。
2. **Project First（项目优先）** —— 不空谈概念，直接做项目。
3. **Copy → Run → Understand（先复制，再运行，再理解）**
4. **Small Steps（小步前进）** —— 一次只做一个小任务。
5. **Evidence over Claims（证据优先）** —— 没验证过就不说「已经完成」。
6. **No Fake Results（不伪造结果）** —— 未验证的内容明确标注 `Not Yet Verified`。
