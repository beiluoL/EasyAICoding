# 📋 Templates（模板）

这里是可以直接复制使用的模板。新建内容时，从对应模板开始，保持一致的结构。

## 模板列表

| 模板 | 用途 | 什么时候用 |
| --- | --- | --- |
| [project-idea.md](project-idea.md) | 记录项目想法 | 脑子里冒出一个想法时 |
| [requirement.md](requirement.md) | 把想法变成需求 | 开始做项目前 |
| [development-plan.md](development-plan.md) | 拆步骤、跟踪进度 | 项目进行中 |
| [bug-report.md](bug-report.md) | 记录 Bug 和解决过程 | 遇到错误时 |
| [prompt.md](prompt.md) | 记录和复用 Prompt | 发现好用的 Prompt 时 |
| [tutorial.md](tutorial.md) | 写教程 | 想贡献教程时 |

## 使用建议

1. 复制模板文件到你的项目或 PR 中
2. 按模板结构填写
3. 不要删除模板自带的说明段落，除非它确实不适用

## 模板与仓库内容的对应关系

- 完整教程结构见 [教程质量标准](../docs/contribution/content-quality.md)
- 案例结构见 [Case 标准](../cases/README.md)
- 提交模板见 [GitHub Issue Templates](../.github/ISSUE_TEMPLATE/)
