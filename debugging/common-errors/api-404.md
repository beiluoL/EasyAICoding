# 接口 404

## 症状

前端调用接口时，Network 里显示：

- `404 Not Found`
- `Cannot GET /api/xxx`
- 页面功能没反应，控制台报 404

## 原因

常见原因：

1. **接口路径写错**：前端请求的地址和后端定义的不一致
2. **请求方法不对**：后端是 `POST`，前端用了 `GET`
3. **后端没启动**：请求发到了不存在的服务
4. **路由顺序问题**：后端没有定义这个接口

## 排查

1. 打开 Network，看请求的完整 URL
2. 和后端接口定义对比：路径、方法、参数
3. 直接在浏览器访问接口地址，看返回什么
4. 确认后端服务在运行、路由已注册

## 解决

- 路径不一致 → 修改前端或后端，让两者一致
- 方法不一致 → 改成 `POST` / `GET` 对应的方法
- 后端没这个接口 → 让 AI 补上，或确认接口文档

## 如何预防

- 前后端接口路径写进文档（README 或 API 说明）
- 前端请求的 URL 用变量统一管理，不要散落各处
