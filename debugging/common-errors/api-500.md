# 接口 500

## 症状

接口返回：

- `500 Internal Server Error`
- 请求失败，Network 里状态码 500

## 原因

服务器内部出错了，常见原因：

1. **代码报错**：后端处理请求时抛异常
2. **数据库问题**：查询失败、连不上
3. **参数问题**：前端传的参数不符合预期
4. **第三方服务失败**：调用的外部 API 挂了

## 排查

1. 看后端日志（终端输出或日志文件），找到异常堆栈
2. 确认是**所有请求**都 500，还是**特定请求**才 500
3. 用 [analyze-stacktrace Prompt](../../prompts/debugging/analyze-stacktrace.md) 分析堆栈
4. 检查数据库连接和外部服务状态

## 解决

- 代码异常 → 让 AI 修复，加上错误处理
- 参数问题 → 检查前端传参格式
- 外部服务 → 确认服务商状态，加超时和重试

## 如何预防

- 后端接口加统一的错误处理，500 时返回有用的错误信息
- 日志里记录请求参数，方便定位
