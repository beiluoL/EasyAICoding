# 数据库连接失败

## 症状

项目启动或操作时报错，例如：

- `Can't connect to MySQL server`
- `connection refused`
- `database "xxx" does not exist`
- `ECONNREFUSED`

## 原因

常见原因：

1. **数据库服务没启动**：装了数据库但没运行
2. **地址或端口不对**：连接配置里地址写错
3. **账号密码错误**：用户名 / 密码不对
4. **数据库不存在**：没有创建对应的数据库
5. **防火墙或网络问题**：远程数据库被拦截

## 排查

1. 确认数据库服务在运行
2. 检查连接配置：地址、端口、用户名、密码、数据库名
3. 用数据库客户端（或让 AI 指导）测试能否连上
4. 查看完整错误信息，区分「连不上」和「认证失败」

## 解决

按排查结果修复：

- 服务没启动 → 启动数据库服务（Windows 服务 / `brew services` / Docker 等，以官方文档为准）
- 配置错误 → 修改连接字符串，注意不要提交到 GitHub
- 数据库不存在 → 创建数据库（让 AI 给你命令）
- 部署环境连不上 → 检查部署平台的环境变量和网络白名单

## 如何预防

- 数据库连接配置放进环境变量（.env），不要硬编码
- README 里写清楚「本地怎么启动数据库」
- 部署和本地使用不同的配置，分别验证
