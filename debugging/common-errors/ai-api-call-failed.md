# AI API 调用失败

## 症状

调用 AI API（如 OpenAI、Anthropic、国内大模型）时失败：

- `401` / `403`（密钥或权限问题）
- `429`（请求太多 / 额度不足）
- `400`（参数错误）
- 超时、`connection timeout`

## 原因

常见原因：

1. **API Key 错误或过期**（见 [API Key 错误](api-key-error.md)）
2. **余额不足**：`insufficient_quota`
3. **参数错误**：模型名拼错、消息格式不对
4. **网络问题**：地区限制、代理、超时
5. **上下文太长**：请求超过模型限制

## 排查

1. 复制完整错误信息（包括错误码）
2. 对照服务商文档理解错误码
3. 检查：Key、余额、模型名、消息格式、网络
4. 让 AI 帮你检查请求代码（用 [debug-error Prompt](../../prompts/debugging/debug-error.md)）

## 解决

- `401` → 检查 / 更换 Key
- `429` → 降低请求频率、检查额度、加延迟
- `400` → 检查模型名和参数格式
- 超时 → 检查网络，必要时设置更长的超时时间
- 上下文超长 → 减少发送的内容或使用摘要

## 如何预防

- Key 放环境变量，不提交仓库
- 代码里统一管理模型名、API 地址
- 请求加错误处理，失败时给出可读提示而不是直接崩
