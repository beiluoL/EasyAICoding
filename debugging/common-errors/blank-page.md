# 前端页面空白

## 症状

- 打开网页，页面一片空白
- 控制台（Console）有红色报错
- 页面只显示一部分，其他部分消失

## 原因

常见原因：

1. **HTML 结构错误**：标签没闭合，浏览器解析失败
2. **JavaScript 报错**：脚本执行中断，页面没渲染
3. **文件路径错误**：CSS / JS 文件找不到（404）
4. **浏览器缓存**：显示的是旧版本

## 排查

1. 按 F12（或右键 → 检查）打开开发者工具
2. 看 **Console（控制台）** 标签里的红色错误，复制完整信息
3. 看 **Network（网络）** 标签里有没有 404 的文件
4. 刷新页面（试试 Ctrl+Shift+R 强制刷新，清除缓存）

## 解决

- 把 Console 里的错误信息发给 AI，用 [debug-error Prompt](../../prompts/debugging/debug-error.md)
- 404 的文件检查路径（文件名大小写、相对路径对不对）
- JavaScript 报错通常是「找不到某个元素」或「某行代码有语法错误」，让 AI 修复

## 如何预防

- 每次修改后都运行验证
- 保持 HTML / CSS / JS 结构清晰，让 AI 改代码时明确「只改一个文件」
