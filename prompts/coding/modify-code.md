# modify-code（修改代码）

## 适用场景

- 已有代码，你想改样式、文案、逻辑
- 你想让 AI 精准修改，不误伤其他功能

## 你需要提供什么

- 文件：`{{FILE}}`
- 要改什么：`{{WHAT_TO_CHANGE}}`
- 改成什么样：`{{NEW_BEHAVIOR}}`
- 不要动的部分：`{{DO_NOT_TOUCH}}`

## 完整 Prompt

```text
请修改文件 {{FILE}}：

现在的问题是 / 我想改成：
{{NEW_BEHAVIOR}}

具体要求：
1. 只修改与本次需求相关的代码
2. 不要动 {{DO_NOT_TOUCH}}
3. 修改前先告诉我你会改哪几处，等我确认
4. 修改后告诉我怎么验证
5. 如果我的要求会破坏现有功能，请先提醒我
```

## 预期行为

- 修改前先说明改动点
- 最小化改动，不碰无关部分
- 有潜在风险时主动提醒

## 常见问题

### 改完功能坏了？

告诉 AI：「这次修改导致 X 功能坏了，请回退这次修改，换一种实现方式。」

### 怎么确认改对了？

要求 AI：「请同时给出验证步骤和预期结果。」
