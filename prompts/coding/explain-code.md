# explain-code（解释代码）

## 适用场景

- 你看不懂 AI 写的代码
- 你想学习一段代码在干什么
- 你想让 AI 用大白话讲清楚某个文件或某个函数

## 你需要提供什么

- 代码：`{{CODE}}` 或文件路径 `{{FILE}}`
- 你想理解的重点（可选）：`{{FOCUS}}`

## 完整 Prompt

```text
我完全不会编程，请帮我解释这段代码：

{{CODE}}

请这样解释：
1. 这段代码整体是做什么的？（一句话）
2. 按顺序解释每一部分，用大白话，像讲故事一样
3. 指出哪一行 / 哪一段最关键，为什么
4. 如果我想改 {{FOCUS}}，应该改哪里？改成什么？
5. 最后用生活里的例子打个比方
```

## 预期行为

- 先得到一句话总结
- 逐段大白话解释，像讲故事
- 明确指出关键部分和修改位置

## 常见问题

### 解释完我还是不懂？

回复：「再用更简单的例子解释第 X 部分，假设我 10 岁。」

### 代码太长，AI 只解释了一部分？

分段发：一次只贴一个文件或一个函数。
