# implement-feature（实现功能）

## 适用场景

- 项目已经存在，你要新增一个功能
- 你知道要做什么，但不知道怎么实现
- 你想让 AI 只改该改的地方，不乱动其他代码

## 你需要提供什么

- 功能描述：`{{FEATURE}}`
- 项目位置 / 相关文件：`{{FILES}}`
- 验证方式（可选）：`{{HOW_TO_VERIFY}}`

## 完整 Prompt

```text
我的项目：{{PROJECT}}
相关文件：{{FILES}}

请帮我实现一个新功能：{{FEATURE}}

要求：
1. 先不要写代码，先说明你的实现思路，等我确认
2. 只修改实现这个功能需要的文件，其他文件不要动
3. 保持现有代码风格
4. 实现后告诉我：改动了哪些文件、怎么运行验证、预期看到什么
5. 用大白话解释你的实现
```

## 预期行为

- AI 先给思路，不直接大改
- 改动范围最小化，只动必要文件
- 得到清晰的运行验证说明

## 常见问题

### AI 改了一大堆文件？

回复：「请只实现 {{FEATURE}}，撤销其他修改，只改动必要的文件。」

### 改完跑不起来了？

用 [debug-error](../debugging/debug-error.md) 流程，把错误信息发给 AI 修复。
