# deploy-project（部署项目）

## 适用场景

- 项目本地跑通了，想上线让别人能用
- 你不知道选什么平台、怎么操作
- 部署后出问题需要排查

## 你需要提供什么

- 项目类型：`{{PROJECT_TYPE}}`（纯前端 / 带后端 / 带数据库 / AI 应用）
- 项目结构说明：`{{STRUCTURE}}`
- 你的需求（可选）：`{{NEEDS}}`（免费、国内可访问、需要自定义域名等）

## 完整 Prompt

```text
我想部署我的项目，请帮我一步步完成。

项目类型：{{PROJECT_TYPE}}
项目结构：
{{STRUCTURE}}

我的需求：{{NEEDS}}

请这样帮我：
1. 先推荐 2-3 个适合的平台，说明各自优缺点（费用、国内访问、难度）
2. 等我选择后，再给具体的部署步骤，每一步写清楚「预期看到什么」
3. 如果需要配置环境变量（Environment Variable），说明哪些是必须的，并提醒我不要把密钥写进代码
4. 部署完成后，给我一份验证清单（打开网址、测试核心功能）
5. 如果我的项目不适合部署或缺少必要文件，先告诉我缺什么
```

## 预期行为

- 得到平台对比而不是直接拍板
- 部署步骤可验证、分步进行
- 明确的环境变量提醒，保护密钥安全

## 常见问题

### 部署后功能坏了？

把「本地正常、线上报错」的现象 + 错误信息发给 AI，用 [debug-error](../debugging/debug-error.md)。

### 平台收费吗？

让 AI 在推荐时明确说明费用，再对照官方文档确认。免费额度随时可能变化。
