# explain-project（解释项目）

## 适用场景

- 你接手（或自己创建）了一个项目，但看不懂它在干什么
- 你打开项目文件夹，面对一堆文件不知道从哪看起
- AI 生成了代码，你想知道它到底做了什么

## 你需要提供什么

- 项目位置或关键文件：`{{PROJECT_PATH}}`
- 你想知道的重点（可选）：`{{FOCUS}}`

## 完整 Prompt

```text
请帮我理解这个项目：{{PROJECT_PATH}}

我完全不会编程，请用大白话解释：

1. 这个项目是做什么的？给谁用？
2. 项目的整体结构是怎样的？每个文件夹 / 主要文件各是干什么的？
3. 它从哪一行代码开始运行？
4. 如果我要运行它，需要做什么？
5. 如果我想改 {{FOCUS}}，应该看哪些文件？

请先给一个「三句话总结」，再展开细节。不要修改任何代码。
```

## 预期行为

- 先得到三句话总结：项目是什么、怎么运行、主要文件
- 得到文件级解释，知道每个文件的作用
- 知道修改某个功能时该看哪些文件

## 常见问题

### AI 解释得太专业？

回复：「请再简单一点，假设我什么都不懂，用生活例子解释。」

### AI 说它看不到项目文件？

确认你是否用工具打开了项目文件夹（[Context（上下文）](../../docs/concepts/context.md)），或者直接把关键文件内容贴给它。
