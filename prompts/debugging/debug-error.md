# debug-error（排查报错）

## 适用场景

- 项目运行报错
- 页面空白、按钮没反应、启动失败
- 你有一串错误信息，但完全看不懂

## 你需要提供什么

- 现象：`{{WHAT_HAPPENED}}`
- 完整错误信息：`{{ERROR_MESSAGE}}`
- 你刚做了什么：`{{WHAT_I_DID}}`
- 相关代码（可选）：`{{CODE}}`

## 完整 Prompt

````text
我的项目报错了，请帮我 Debug。

现象：{{WHAT_HAPPENED}}

完整错误信息：
```text
{{ERROR_MESSAGE}}
```

我刚才的操作：
{{WHAT_I_DID}}

我的环境：
- 工具 / 编辑器：{{TOOL}}
- 操作系统：{{OS}}

请这样帮我：
1. 先用大白话解释这个错误是什么意思
2. 列出可能的原因，按可能性排序
3. 给出最小改动方案的修复步骤，一步一步来
4. 每一步都说清楚「预期看到什么」
5. 如果信息不够，先问我问题，不要乱猜
````

## 预期行为

- 错误被翻译成大白话
- 得到按可能性排序的原因列表
- 一步一步的修复方案，每步可验证

## 常见问题

### 错误信息太长，要全贴吗？

尽量全贴，尤其是前 20 行和最后 20 行。AI 需要完整信息才能定位。

### AI 给的方案没效果？

把新的错误信息或「没效果」的事实反馈给它，让它换思路。不要自己乱改代码。
