# Tutorial 03 · Prompts

## 开始 Prompt

```text
我完全不会编程。请帮我做一个 Todo 应用：

技术：HTML + CSS + JavaScript，三个文件 index.html、style.css、script.js

功能：
1. 输入框 + 添加按钮
2. 任务列表
3. 点击任务标记完成（删除线 + 变灰）
4. 删除按钮
5. 空列表显示「还没有任务」

界面简洁，代码有中文注释。先告诉我思路，我确认后再写。
```

## 修改 Prompt（加统计）

```text
请给 todo-app 加两个功能：
1. 顶部显示「已完成 X / 共 Y」
2. 「清空已完成」按钮
只改必要文件，先告诉我改哪里。
```

## Debug Prompt

```text
Todo 应用出问题：
现象：{{描述}}
控制台错误：{{粘贴完整错误}}
请用大白话解释，只改必要文件，告诉我怎么验证。
```

## 部署 Prompt

```text
我想把 todo-app 部署到 GitHub Pages。请一步步教我：
1. 创建 GitHub 仓库并推送代码
2. 开启 GitHub Pages
3. 每一步写清「预期看到什么」
4. 提醒我可能遇到的坑
```
