# 🛠 Tutorials（教程）

教程是「照着做就能做出真实项目」的完整指南。每个教程遵循统一结构：

```text
你要做什么
↓
最终会得到什么
↓
准备工作
↓
Step 1 → Step 2 → Step 3 ...
↓
运行
↓
常见错误
↓
下一步
```

## 使用建议

1. **按顺序做**：每个教程建立在前一个之上
2. **不要跳过运行**：代码不运行，教程就没有意义
3. **遇到错误是好事**：用 [Debug 流程](../debugging/README.md)
4. **完成一个再做下一个**：一次只做一个教程

## 教程与案例的关系

教程 = 手把手教学；[案例](../cases/README.md) = 记录完整项目。做完教程后，可以用案例结构把自己的项目记录下来。
