# Tutorial 05 · Prompts

## 项目启动 Prompt

```text
我完成过网页、Todo、AI 聊天、RAG 应用。现在想做自己的 AI 工具。

我的想法：{{你的想法}}

请帮我：
1. 分析这个想法，指出最简单实现方式
2. 设计 MVP（最小可用版本）
3. 拆成小任务，一次只给我一个
4. 每步先运行验证再继续
5. 用已学的技术栈，不引入新技术
```

## 任务执行 Prompt

```text
下一个任务：{{AI 给的任务}}

请只实现这个任务。改完告诉我：
- 改了哪些文件
- 怎么运行验证
- 预期看到什么
```

## 打磨 Prompt

```text
请检查我的项目 {{项目名}}，从新手体验角度指出：
1. 哪些场景会出错或困惑
2. 界面哪里不清晰
3. 错误提示哪里不友好
然后按优先级给出改进建议，我确认后再改。
```

## Debug Prompt

```text
我的项目 {{项目名}} 出问题。
现象：{{描述}}
完整错误信息：{{粘贴}}
最近修改：{{我做了什么}}
请用大白话解释，检查是否与最近修改有关，给最小修复方案。
```
