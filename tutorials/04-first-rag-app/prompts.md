# Tutorial 04 · Prompts

## 创建结构

```text
我完成过 AI 聊天和 Todo 应用，现在想做第一个 RAG 应用（基于文档问答）。

技术栈：Node.js + Express + 原生前端 + SQLite（存文档块）+ 一个简单的向量搜索方案（请选最简单、最适合新手的，例如 sqlite-vec 或内存向量检索）

项目结构：
rag-app/
├── server.js
├── public/
│   ├── index.html
│   ├── style.css
│   └── script.js
├── documents/          # 放资料
├── .env
├── .gitignore
└── package.json

先告诉我每个文件的作用和整体流程，我确认后再创建。
```

## 实现加载切分

```text
请在 rag-app 里实现：
1. 启动时读取 documents/ 里的文本文件
2. 把每个文件按段落切分，保存到数据库
3. 每条记录包含：内容、来源文件名、序号
4. 用中文注释，先说明思路
```

## 实现问答

```text
请在 rag-app 里实现问答流程：
1. 用户提问
2. 找到数据库里与问题最相关的内容块（关键词匹配即可，V0.1 不追求完美）
3. 把相关内容 + 问题发给 {{你的AI服务商}}，要求「只根据提供的资料回答，资料里没有就说明不知道」
4. 返回回答和引用的来源
5. 失败时返回可读错误
```

## 实现界面

```text
请实现 rag-app 的前端：
1. 显示已加载的文档数量
2. 提问框 + 发送按钮
3. 回答区，显示回答和来源文件名
4. 加载状态和错误提示
5. 界面简洁，中文注释
```
