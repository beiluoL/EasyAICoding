# Tutorial 01 · Prompts

## 开始 Prompt

```text
我完全不会编程。请帮我做一个个人网站：

1. 只有一个 index.html 文件
2. 显示我的名字：{{你的名字}}
3. 一句话介绍：{{你的介绍}}
4. 一个按钮，点击后显示「你好，我是 {{你的名字}}」
5. 配色简洁，用中文注释说明哪里改颜色

先不要写代码，先告诉我页面结构，我确认后再生成。
```

## 修改 Prompt

```text
请修改 index.html：
- 背景色改成浅蓝色
- 按钮改成圆角
- 其他内容不要动

改完告诉我改了哪几处，怎么验证。
```

## Debug Prompt

```text
我创建了 index.html，但出现这个问题：
现象：{{描述}}
错误信息：{{完整错误}}
请用大白话解释原因，只修改必要部分。
```
