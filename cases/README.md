# 🎯 Beginner Cases（入门案例）

Beginner Case = 一个**小白真的能做完**的项目记录。

每个案例包含：

```text
README.md         项目是什么、适合谁、最终效果
requirements.md   目标、功能、MVP
steps.md          一步步怎么做
prompts/          实际使用的 Prompt
verification.md   如何运行、如何验证
lessons.md        学到了什么、哪里容易出错
```

## 怎么使用案例

1. 从 **001** 开始，按顺序做
2. 每个案例先读 README，再读 steps
3. 复制 prompts/ 里的 Prompt 发给 AI
4. 每完成一步，用 verification.md 验证
5. 做完后读 lessons.md，记录你的收获

## 案例标准

提交新案例前确认：

- [ ] 一个小白真的能按步骤做完
- [ ] 有完整的 requirements / steps / prompts / verification / lessons
- [ ] 验证结果真实，未验证写 `Not Yet Verified`
- [ ] 没有 API Key、密码等敏感信息

## 提交案例

使用 [Case Submission 模板](../.github/ISSUE_TEMPLATE/case-submission.yml) 或直接提交 PR（见 [贡献指南](../CONTRIBUTING.md)）。

## Verification

- 案例中的步骤基于通用实践整理
- 每个案例的 verification.md 都标注了验证状态
