## 如何把你的项目放进来

1. 完成一个 [Beginner Case](../beginner/README.md) 或你自己的项目
2. 按 [Case 标准](../README.md) 记录过程
3. 提交 PR（见 [贡献指南](../../CONTRIBUTING.md)）

展示内容包括：

- 项目名称和一句话介绍
- 项目链接（部署后的网址）
- 使用的工具和 Prompt
- 完成时间
- 遇到的问题和解决过程
