# Case 002 · 开始 Prompt

```text
我完全不会编程。请帮我做一个 Todo 应用（待办清单）：

技术：HTML + CSS + JavaScript，三个文件：index.html、style.css、script.js

功能：
1. 顶部输入框 + 「添加」按钮
2. 下面是任务列表
3. 点击任务可以标记完成（文字加删除线、变灰）
4. 每条任务旁边有「删除」按钮
5. 列表为空时显示「还没有任务」

要求：
- 界面简洁、适合新手，代码里用中文注释
- 先不要写代码，先告诉我文件结构和功能实现思路，我确认后再开始
```
