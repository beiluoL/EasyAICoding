# Case 002 · Todo 应用

## 项目是什么

用 HTML + CSS + JavaScript 做一个 Todo 应用（待办清单）：可以添加任务、标记完成、删除任务。

## 适合谁

- 做过 [Case 001](../001-personal-website/README.md) 的人
- 想第一次体验「交互式应用」的人

## 难度

⭐⭐

## 学习目标

- 理解 JavaScript 如何操作页面内容
- 理解「数据在内存里」和「数据在数据库里」的区别
- 学会把功能拆成小任务
- 学会用控制台排查 JavaScript 错误

## 需要什么

- 一个 AI 工具
- 一个项目文件夹 `todo-app`
- 约 1-2 小时

## 最终效果

打开页面：输入任务 → 添加 → 出现在列表 → 可以标记完成 → 可以删除。刷新页面后数据丢失（这是预期，下一步才接数据库）。
