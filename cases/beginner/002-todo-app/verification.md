# Case 002 · Verification（验证）

## 如何运行

双击 `todo-app/index.html`，用浏览器打开。

## 如何验证

| 检查项 | 操作 | 预期结果 |
| --- | --- | --- |
| 添加 | 输入文字 → 点添加 | 任务出现在列表，输入框清空 |
| 空状态 | 清空所有任务 | 显示「还没有任务」 |
| 完成 | 点击任务 | 文字加删除线、变灰 |
| 取消完成 | 再点一次 | 恢复原样 |
| 删除 | 点删除按钮 | 任务消失 |
| 统计 | 完成 1 个任务 | 显示「已完成 1 / 共 X」 |
| 清空已完成 | 点按钮 | 已完成任务全部消失 |
| 控制台 | F12 打开 Console | 无红色错误 |
