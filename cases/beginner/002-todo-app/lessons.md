# Case 002 · Lessons（经验教训）

## 学到了什么

- **JavaScript 是「大脑」**：添加、删除、完成状态都由它控制
- **事件（Event）**：点击按钮、点击任务，都是事件，代码「监听」事件并响应
- **DOM（页面结构）**：JavaScript 通过操作 DOM 来增删页面元素
- **内存 vs 数据库**：刷新就丢，是因为数据只存在内存/页面里，没有持久化

## 哪里容易出错

### 1. 添加按钮没反应

常见原因：按钮的 `id` 和 JavaScript 里写的不一致，或 JavaScript 文件没引入。检查 `script.js` 是否在 HTML 末尾引入。

### 2. 点击任务没标记完成

常见原因：事件绑定写在了动态创建的元素上，需要「事件委托」（Event Delegation）。不用懂原理，把这个词告诉 AI 即可。

### 3. 样式不生效

检查 `style.css` 是否在 HTML 里引入，以及文件路径是否正确。

## AI 为什么容易犯错

- **一次性写太多**：AI 常把全部功能一次写完，出错后难定位。所以步骤里要求「先基础版，再加功能」
- **命名不一致**：AI 可能在不同文件里用了不同的 id / 类名。出现问题时，让它先检查命名一致性

## 一句话总结

> 交互应用 = 用户操作 + 代码响应。先把「响应」做对，再谈好不好看。
