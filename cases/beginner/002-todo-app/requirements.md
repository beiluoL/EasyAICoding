# Case 002 · Requirements（需求）

## 目标

做一个浏览器里能用的 Todo 应用：添加、完成、删除任务。

## 功能

必须要有（P0）：

- [ ] 输入框 + 添加按钮
- [ ] 任务列表展示
- [ ] 点击任务标记完成（样式变化）
- [ ] 删除按钮
- [ ] 空列表时显示提示文字

应该要有（P1）：

- [ ] 已完成任务数量统计
- [ ] 清空已完成任务按钮

可以以后做（P2）：

- 数据保存（localStorage / 数据库）
- 拖拽排序
- 分类、截止日期

## 非功能要求

- 单页应用：`index.html` + `style.css` + `script.js`（或单一 HTML 文件）
- 不引入框架和构建工具
- 代码结构清晰，变量名有意义

## MVP（最小可用版本）

**输入 → 添加 → 显示 → 标记完成 → 删除**，五项闭环。

## 验收标准

- [ ] 添加任务后立即出现在列表
- [ ] 点击任务可切换完成状态
- [ ] 删除按钮能移除任务
- [ ] 空状态有提示
- [ ] 控制台无报错
