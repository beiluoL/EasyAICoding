# Case 001 · 个人网站

## 项目是什么

用 HTML + CSS 做一个展示自己的个人网站：一个页面，包含名字、介绍、照片（可选）、按钮。

## 适合谁

- 完全不会编程的人
- 第一次做「真实项目」的人
- 想快速获得成就感的人

## 难度

⭐（最低）

## 学习目标

- 理解「文件」和「项目文件夹」
- 理解 HTML 是骨架、CSS 是样式
- 会用浏览器运行和刷新页面
- 完成第一次「让 AI 写代码 → 保存 → 运行」的闭环

## 需要什么

- 一个 AI 工具（Codex / Cursor / Claude Code 任选）
- 一个文件夹（例如桌面 `my-website`）
- 约 30-60 分钟

## 最终效果

浏览器打开 `index.html`，看到一个属于自己的页面：名字、介绍、彩色按钮，按钮点击后有反应。
