# Case 001 · Lessons（经验教训）

## 学到了什么

- **HTML = 骨架**：页面内容（文字、按钮）靠它
- **CSS = 样式**：颜色、大小、位置靠它
- **JavaScript = 交互**：按钮点击反馈靠它
- **运行 = 用浏览器打开文件**，改完刷新就能看到变化
- **AI 是帮手**：说清楚「要什么 + 不要什么」，代码质量更高

## 哪里容易出错

### 1. 文件名不是 .html

保存成 `index.html.txt` 会导致双击打不开。确认文件扩展名是 `.html`。

### 2. 复制代码不完整

AI 给的代码很长，容易复制漏掉结尾。保存后检查文件末尾是否有 `</html>`。

### 3. 按钮没反应

通常是 JavaScript 报错。按 F12 打开控制台，把红色错误发给 AI。

### 4. 改了一处，其他地方乱了

修改时只改一处就刷新验证，不要一次性改很多处。

## AI 为什么容易犯错

- **需求不明确**：你没说「只有一个文件」，AI 可能创建多个文件
- **上下文丢失**：新会话不知道你之前的要求，需要重新说明
- **过度设计**：AI 默认会做得复杂，所以要主动说「保持简单」

## 一句话总结

> 第一个项目不用完美，跑起来、看到自己的名字，就已经赢了。
