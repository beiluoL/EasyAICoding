# Case 001 · Requirements（需求）

## 目标

做一个单页个人网站，展示自己的基本信息。

## 功能

必须要有（P0）：

- [ ] 页面显示：名字 + 一句话介绍
- [ ] 一个按钮，点击后显示一条欢迎消息
- [ ] 页面有基础配色和布局

应该要有（P1）：

- [ ] 一张自己的照片或占位图
- [ ] 联系方式（邮箱或社交媒体链接）

可以以后做（P2）：

- 多个页面
- 响应式设计（适配手机）
- 部署上线

## 非功能要求

- 项目只有一个文件夹，代码结构清晰
- 用 HTML + CSS + JavaScript，不引入框架
- 不依赖网络即可运行（本地双击打开）

## MVP（最小可用版本）

**一个 `index.html` 文件**：名字 + 介绍 + 按钮，能用浏览器打开，按钮能弹消息。

## 验收标准

- [ ] 双击 `index.html` 能在浏览器打开
- [ ] 名字和介绍显示正确
- [ ] 点击按钮有反馈
- [ ] 修改文字后刷新页面能看到变化
