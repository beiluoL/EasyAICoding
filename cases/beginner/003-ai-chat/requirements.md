# Case 003 · Requirements（需求）

## 目标

做一个网页版 AI 聊天：用户提问，AI 回答。

## 功能

必须要有（P0）：

- [ ] 输入框 + 发送按钮
- [ ] 对话显示区（用户消息 + AI 消息）
- [ ] 调用 AI API 获取回答
- [ ] 请求期间显示「思考中…」状态
- [ ] 出错时显示可读的错误提示

应该要有（P1）：

- [ ] 回车键发送
- [ ] 对话自动滚动到底部
- [ ] 清空对话按钮

可以以后做（P2）：

- 多轮上下文记忆
- Markdown 渲染
- 流式输出（Stream）

## 非功能要求

- API Key 只存在后端环境变量
- 前后端分离或简单分层，代码结构清晰
- 不泄露 Key，不写死模型密钥

## MVP（最小可用版本）

**输入 → 后端转发给 AI API → 显示回答**，单轮对话即可。

## 验收标准

- [ ] 能完成一轮「提问 → 回答」
- [ ] 请求中有加载状态
- [ ] Key 不在前端代码里
- [ ] 错误时有提示，而不是白屏
