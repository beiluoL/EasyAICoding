# Case 005 · 开始 Prompt

```text
我完成过几个小项目（网页、Todo、AI 聊天、带数据库的博客），现在想做自己的 AI 工具。

我的想法：{{你的想法}}

请帮我：
1. 分析这个想法，指出最简单的实现方式
2. 设计 MVP（最小可用版本）
3. 拆成小任务，一次只给我一个任务
4. 每一步都让我先运行验证再继续
5. 用已学的技术栈（Node.js + Express + SQLite + 原生前端），不引入新技术
```

## 后续任务 Prompt（示例）

```text
下一个任务：{{AI 给你的任务}}

请只实现这个任务，改完告诉我：
- 改了哪些文件
- 怎么运行验证
- 预期看到什么
```
