# Case 005 · AI 工具

## 项目是什么

做一个你自己的 AI 工具：一个解决具体问题的小应用，例如「文章摘要器」「英文学习助手」「周报生成器」。

这是 V0.1 的毕业项目：把前四个案例学的所有东西组合起来。

## 适合谁

- 完成 [Case 001](../001-personal-website/README.md) 到 [Case 004](../004-ai-blog/README.md) 的人
- 有一个真实想法、想做出第一个「作品」的人

## 难度

⭐⭐⭐⭐⭐

## 学习目标

- 独立规划一个完整项目（想法 → 需求 → 拆任务）
- 组合使用：前端界面 + 后端 + AI API + 数据保存
- 学会边做边验证，管理项目节奏
- 为部署上线做准备

## 需要什么

- 前面四个案例的基础
- 一个真实想法（可以用 [project-idea 模板](../../../templates/project-idea.md)）
- 约 1-2 周（每天 1 小时）

## 最终效果

一个能解决你真实问题的 AI 工具，本地完整可用，具备部署条件。
