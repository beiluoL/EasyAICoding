# Case 004 · AI 博客

## 项目是什么

做一个 AI 辅助的博客：你可以写文章、保存文章、浏览文章列表，还能让 AI 帮你生成文章草稿。

## 适合谁

- 完成 [Case 003](../003-ai-chat/README.md) 的人
- 想第一次体验「数据保存 + AI 结合」的人

## 难度

⭐⭐⭐⭐

## 学习目标

- 理解数据库（Database）的作用：数据长期保存
- 理解 CRUD（增删改查）：Create / Read / Update / Delete
- 把 AI 功能（生成草稿）接入已有应用
- 学会规划一个「多页面、多功能」项目

## 需要什么

- 完成 Case 003 的基础（Node.js 后端 + 前端）
- 一个 AI API 账号
- 约 3-4 小时

## 最终效果

本地运行：可以写文章 → 保存到数据库 → 首页显示文章列表 → 打开文章详情 → 点「AI 帮我写草稿」输入主题生成草稿。
