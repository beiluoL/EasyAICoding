# Case 004 · Requirements（需求）

## 目标

做一个带数据库的 AI 博客：文章可以长期保存，AI 可以辅助写作。

## 功能

必须要有（P0）：

- [ ] 首页：文章列表
- [ ] 新建文章：标题 + 内容 + 保存
- [ ] 文章详情页
- [ ] 删除文章
- [ ] 数据保存到数据库，重启后还在

应该要有（P1）：

- [ ] 编辑已有文章
- [ ] AI 生成草稿：输入主题 → 生成文章内容（草稿）
- [ ] 文章按时间排序

可以以后做（P2）：

- 用户登录和权限
- 分类、标签
- 图片上传
- 部署上线

## 非功能要求

- 数据库使用 SQLite（一个文件就是数据库，最简单）
- API Key 只存环境变量
- 代码结构清晰：路由、数据库操作、前端页面分开

## MVP（最小可用版本）

**创建文章 → 保存到数据库 → 列表显示 → 查看详情 → 删除**，不含 AI 功能。

## 验收标准

- [ ] 文章能保存，重启项目后还在
- [ ] 列表 / 详情 / 删除可用
- [ ] AI 生成草稿可用
- [ ] 没有敏感信息泄露
