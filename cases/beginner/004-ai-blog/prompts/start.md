# Case 004 · 开始 Prompt

## 第一步：MVP

```text
我完全不会编程，想做一个带数据库的博客网站。先做 MVP（不加 AI）：

技术栈：Node.js + Express + SQLite + 原生前端

功能：
1. 首页显示文章列表（标题 + 时间）
2. 新建文章页（标题 + 内容 + 保存）
3. 文章详情页
4. 删除文章

要求：
- 数据库用 SQLite，自动创建表
- 接口路径：/api/posts 等，用中文注释
- 前端三个页面：列表、新建、详情
- 先告诉我接口设计和数据库表结构，我确认后再写代码
```

## 第二步：AI 生成草稿

```text
在新建文章页加一个功能：输入主题 → 点击「AI 生成草稿」→ 调用后端接口 → 后端用 AI API 生成文章草稿 → 填入内容编辑框。

要求：
- AI 调用放在后端，API Key 只存在 .env
- 生成期间显示「生成中…」，失败显示可读错误
- 只修改必要文件，先告诉我改动计划
```
